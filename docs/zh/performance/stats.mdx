@oasishub/engine-toolkit-stats 包主要用来显示相机的渲染状态，只需要为相机节点添加 `Stats` 组件：

```typescript
import { Engine } from "@oasishub/engine";
import { Stats } from "@oasishub/engine-toolkit-stats";

cameraEntity.addComponent(Camera);
cameraEntity.addComponent(Stats);
```
