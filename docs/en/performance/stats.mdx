@oasishub/engine-toolkit-stats package is mainly used to display the rendering status of the camera. You only need to add the `Stats` component to the camera node:

```typescript
import { Engine } from "@oasishub/engine";
import { Stats } from "@oasishub/engine-toolkit-stats";

cameraEntity.addComponent(Camera);
cameraEntity.addComponent(Stats);
```
